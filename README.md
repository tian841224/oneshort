# OneShort - 專為遊戲玩家打造的即時組隊媒合系統

![OneShort Hero](assets/hero.png)

OneShort 是一個高效、即時且現代化的遊戲組隊平台。無論你是要攻略高難度副本，還是尋找輕鬆練功的夥伴，OneShort 都能幫你快速成團。不再需要在大廳或DC刷頻，我們提供最直觀的介面，讓你一鍵掌握當前所有隊伍動態。

## 🌟 核心特色

### 🚀 即時同步，資訊零時差
隊伍人數、成員異動訊息即時推送。你看到的列表永遠是最新。

### 🛡 靈活的隊伍管理
- **審核機制**：隊長可自由設定「自由加入」或「手動審核」，精確篩選最佳隊友。
- **密碼保護**：支援私密隊伍模式，適合公會活動或熟人約戰。
- **房號直達**：每個隊伍都有唯一的 Hash ID，複製貼上即可快速找到指定隊伍。

### 🎭 空缺職位多樣性
隊長在建立隊伍時可以指定特定空缺職位，大幅提高媒合成功率。

### 👤 完整的角色整合
預先登錄你的遊戲角色。加入隊伍時，系統將自動帶入你的職業與等級資訊，讓隊長一目了然你的戰鬥戰力。

---

## 🎮 如何開始使用？

1. **DC 登入**：綁定DC帳號，快速進入媒合大廳。
2. **角色管理**：建立與管理多個遊戲角色，隨時切換不同職業送出申請。
3. **探索隊伍**：使用過濾系統，根據活動類型、目標來篩選。
4. **加入冒險**：一鍵送出申請，透過即時通知掌握審核進度。
