# OneShort 功能總覽

本文件依模組整理 OneShort 的主要功能，說明每個模組對玩家與管理者提供的能力。

## 1. 身份與登入

所有登入方式最終都解析成同一種帳號層身份（actor），底下可掛多個遊戲角色（character）：

- **快速登入（Quick Login）**：以「角色代碼 + PIN（4–6 位數字）」登入；角色代碼不存在時自動建立帳號與主要角色，讓玩家不需註冊流程即可開始使用
- **Discord OAuth**：以 Discord 帳號登入；也可在既有快速登入帳號上補綁 Discord
- **帳號綁定與合併**：Discord 已綁到其他帳號時，提供帳號合併流程（角色、通知、回報紀錄一併搬移），避免玩家因多個入口產生分裂帳號
- **Session 管理**：JWT 以 Cookie 保存，access token 過期時由後端自動以 refresh token 輪替，前端不需顯式呼叫 refresh
- **訪客（quick guest）**：未登入者仍可參與部分流程（如快速隊伍、大廳聊天），設定暱稱、職業與等級後可比照登入玩家顯示身份

## 2. 隊伍系統

隊伍是平台的核心物件，支援多種型態與完整的生命週期管理。

### 隊伍類型

- **目標類型**：練功（選擇地圖）、BOSS / 團體任務（選擇目標）
- **生命週期**：立即（快速）隊伍——重視即時性、以快取為主、閒置自動關閉；排程隊伍——指定未來時間
- **可見性**：公開隊伍、密碼房（需驗證密碼）、公會隊伍（僅公會成員可見）

### 玩家能力

- 建立隊伍：設定目標、席位（職業需求）、人數、密碼與「是否允許快速登入玩家」等條件
- 搜尋與篩選：依目標、狀態、條件瀏覽公開隊伍列表，列表透過即時事件保持新鮮
- 申請加入 / 直接加入：符合條件時可自動核准；申請中的隊伍會顯示於「我的申請」聚合頁
- 隊伍聊天室：成員可即時交談，訊息保留最近 100 筆、最久 24 小時，發送者快照包含職業與等級
- 黑名單：玩家可封鎖特定角色，避免互相加入對方隊伍

### 隊長能力

- 審核申請（核准 / 拒絕）、管理席位（新增 / 調整 / 移除）、踢出成員
- 關閉、重新開放或解散隊伍
- 核准新成員會刷新隊伍的招募曝光時間；閒置隊伍由背景工作發出警告並自動關閉

### 一致性保護

- 同一角色同時間只能參與一個立即活動（活動排他鎖）
- 申請被核准時，自動取消該角色在其他隊伍的待審申請

## 3. 公會系統

公會提供長期社群協作能力，成員分為會長、幹部與一般成員三種角色。

### 成員與治理

- 建立公會、申請加入（由會長 / 幹部審核）、退出、解散
- 會長可設定成員上限、轉讓會長、調整成員角色；容量檢查在資料庫交易內完成
- 成員異動、角色變更、解散等事件會即時推播給受影響的成員

### 公會內容

- **公會公告**：發布、編輯、置頂公告
- **公會聊天室**：公會層級的即時聊天
- **公會隊伍**：可見性限定公會內的隊伍，會長 / 幹部可管理所有公會隊伍（含自動配對產生的隊伍）
- **行事曆**：查詢自己角色未來 7 天內已排入的 BOSS 公會隊伍

### BOSS 自動配對

公會可為週期性 BOSS 活動自動組隊：

- 成員以「角色」為單位設定偏好：想打的 BOSS（有序，代表優先順位）與可參與時段
- 會長 / 幹部維護公會預設 BOSS 設定：每個職業需求可設多個職業（OR 條件）、最低與上限人數
- 自動配對以週為週期，依時段與偏好順位分配；同一角色一個週期只進一個隊伍
- 支援試算（不落地）、產生可編輯草案、幹部手動調整後確認成團；確認時仍會驗證成員資格與席位合法性
- 配對完成、公告更新、成員異動都會透過公會房間即時推播

## 4. 通知系統

- **通知中心**：查詢個人通知、未讀數、單筆 / 全部標為已讀、刪除
- **即時推播**：申請結果、成員異動、公會事件等在發生當下透過 WebSocket 推送
- **通知偏好**：可調整通知相關設定
- 通知以帳號（actor）為唯一收件單位，快速登入與 Discord 登入共用同一份通知

## 5. 公告與跑馬燈

- **平台公告**：管理端發布的 Markdown 公告（單則上限 4000 字元），前端以公告視窗呈現，支援優先度排序
- **NoticeBar 跑馬燈**：獨立於公告的一行提示文字（上限 240 字元），用於輕量即時提醒

## 6. 大廳聊天

- 全站公開的即時聊天室，登入者與訪客皆可發言
- 訪客未設定角色資訊時以「遊客」顯示；已設定則比照登入玩家顯示職業與等級
- 具備發言節流保護，歷史保留最近 100 筆、最久 24 小時

## 7. 在線統計

- 顯示平台即時活躍程度（在線人數）
- 每日統計由背景工作於午夜彙整

## 8. 管理端

### 管理後台

- 平台統計檢視
- 封禁名單管理
- 隊伍與公會的檢視與移除
- 公告與 NoticeBar 的建立、更新、刪除

### Telegram Bot

管理人員可透過 Telegram 群組指令完成部分營運操作，不必進入完整後台：

- 公告管理：`/announce`、`/clear`、`/delete`
- NoticeBar 管理：`/notice`、`/notice-clear`
- 問題回報維護：`/bugs`、`/bug`、`/bug-status`、`/bug-reply`

Webhook 受 secret token 與群組白名單保護，並具備重試去重機制。

## 9. 其他支援功能

- **問題回報**：玩家可回報問題，管理端可查詢、更新狀態與回覆
- **OCR 掃描**：遊戲截圖解析（目前停用，保留模組）
