# OneShort 功能介紹

以下依 2026-10-03 的實作整理，從玩家實際使用的流程介紹主要功能。

## 找隊伍與快速開團

- **依活動找團**：瀏覽組隊任務、BOSS、練功與快速隊伍，搜尋名稱或目標。
- **看見適合的職缺**：依職業、等級、任務／地圖／BOSS 及可加入狀態篩選。
- **快速建立**：填寫房名、頻道與備註，依需要設定公開加入、審核或密碼房。
- **一般開團**：指定活動目標、職缺與條件；BOSS 隊伍可設定預約時間。
- **分享與接續操作**：用隊伍連結邀請朋友，也能從「我的隊伍」回到自己正在參與的房間。

訪客也能建立與加入支援的隊伍。可否加入仍受房型、密碼、審核、名額及其他條件限制，畫面會提示下一步。

## 從申請到成團

### 玩家

- 選擇自己的角色與符合條件的職缺；多角色申請分別顯示結果。
- 直接加入，或等待房主核准後入隊。
- 查看待審、已接受、已拒絕及已取消的申請，並在允許時取消申請或離隊。
- 在隊伍聊天室溝通頻道、出發時間與分工。

### 房主

- 審核申請、調整職缺的職業與等級需求、開關招募名額。
- 編輯房間設定，管理成員與移除不再參與的隊員。
- 調整公開／隱藏狀態，或結束隊伍。

進入房間查看與正式加入是不同狀態；送出待審申請也不代表已經取得名額。

## 帳號與多角色

- **登入方式**：Discord，或角色代碼＋PIN。
- **角色管理**：新增、編輯與切換角色，維護名稱、職業與等級，管理啟用狀態。
- **帳號設定**：更新 PIN、連結或解除 Discord；遇到既有帳號衝突時提供合併確認流程。
- **參與紀錄**：登入後可查看最近 30 天的隊伍參與摘要，包含離隊後的紀錄。

未登入訪客與以角色代碼＋PIN 登入的玩家是不同身分。訪客只使用支援的流程；個人角色管理、完整參與紀錄與公會成員操作需要登入。

## 聊天與通知

| 空間 | 使用方式 |
| --- | --- |
| 大廳聊天 | 找團與公開交流；訪客首次發言前需補齊名稱、職業與等級 |
| 隊伍聊天 | 依房間權限開放，方便隊員溝通 |
| 公會聊天 | 提供公會成員交流的空間 |
| 個人通知 | 查看申請結果、成員異動與公會相關通知，管理未讀及已讀狀態 |

聊天和隊伍狀態搭配即時更新；連線狀態改變時，畫面也會重新取得資料。聊天紀錄有保存範圍，不作為永久對話存檔。

## 公會協作

### 成員、公告與活動

- 搜尋、建立或加入公會，支援直接加入、申請審核及密碼等入會方式。
- 依會長、幹部與成員權限處理入會申請、成員角色與會長轉移。
- 發布、編輯與置頂公會公告。
- 建立與查看公會限定隊伍，從個人行事曆查看角色已排入的 BOSS 活動。

### BOSS 配對

成員先把可參與的條件填好，幹部再集中安排：

1. **角色偏好**：每個角色分別設定 BOSS 優先順序與可參加時段。
2. **本輪參與**：選擇自動參與，或手動確認本輪；日期以畫面顯示的配對週期為準。
3. **成團條件**：幹部設定人數、等級與職業需求，查看候選角色及試算結果。
4. **草案調整**：檢查時段與成員分配，必要時調整後再確認產生隊伍。
5. **查看安排**：從公會隊伍、行事曆及配對紀錄追蹤結果。

系統也支援依已儲存設定進行週期性自動配對。是否能成團取決於參與名單、時段及職缺條件；修改偏好不會自動改寫已產生的隊伍。公會行事曆是站內功能。

## 隊伍攻略與合作小工具

在有對應攻略的組隊任務中，已登入的房主與成員可直接閱讀隊伍攻略，並使用共享工具協作，例如：

- 勾選清單、計數與共同進度
- 角色分工與指派
- 順序紀錄、圖上標記與解題輔助
- 特定任務的門、箱子、票券或獎勵紀錄

工具依任務與攻略配置提供。共享進度會同步給隊友；桌面可使用工具視窗，手機以適合小螢幕的面板操作。

## 手機使用與問題回報

桌面提供隊伍預覽與可調整的聊天面板；手機提供單欄列表、底部導覽及聊天面板。網站也提供問題回報入口，可查看公開回報、處理狀態與開發回覆。

## 常見問題

### 一定要先登入嗎？

不用。可以先瀏覽公開隊伍，部分開團、加入及大廳聊天流程支援訪客。若目前房型或操作需要帳號，依畫面提示登入即可。

### 快速隊伍就是預約隊伍嗎？

快速隊伍用於簡化即時招募；預約 BOSS 團則指定未來時間。要改成未來活動時，應建立支援預約的隊伍，並依表單允許的設定操作。

### 送出申請後就可以當作入隊了嗎？

需要審核時，請等結果顯示已接受並確認成員名單。房間可查看、申請待審與正式隊員各有不同的操作權限。

### 歷史紀錄還在，為什麼打不開原本的隊伍？

參與紀錄保留的是摘要。原房間關閉或過期後，可能無法再開啟完整詳情。

### 可以在這裡下載並自行部署嗎？

這個儲存庫提供產品介紹與精簡架構文件，未包含完整前後端程式碼與部署套件。
